## A. 재고 수량 정책 (기준일 2026-10-14)

### 1. 수정 범위

| 구분 | 내용 |
| --- | --- |
| 변경 사항 | 보유수량·판매가능수량 증감 방식을 장부 방식으로 통일 |
| 변경 용어 | "도매수량" 폐기, "보유수량"으로 통일 |
| 적용 대상 | 내도매상품 / 도매주문상품 / 내소매상품 전체 |
| 적용 이벤트 | 소매 주문 접수, 도매 주문 접수, 소매·도매 취소·반품 재고 반영, 구매자 즉시취소, 도매 구매 배송확정 |
| 비변경 | 잠금 규칙(판매상태·노출여부·화면 접근), 재고 반영 체크박스 노출 조건, 품목별 부분 처리 미지원 |
| 데이터 | 운영 데이터 없음. 오픈 시점에 데이터를 초기화한다. 이관·보정 없음 |

### 2. 용어 정의

| 용어 | 정의 |
| --- | --- |
| 보유수량 | 계정 + 상품코드 단위로 저장한다 |
| 판매가능수량 | 소매정보 단위로 저장한다 |
| 도매 가용재고 | 보유수량 − 판매가능수량으로 산출한다. 저장하지 않는다 |
| 주문가능수량 | 도매 가용재고와 같다 |

### 3. 정의

#### 3-1. 저장 단위

1. 보유수량은 계정 + 상품코드 단위로 저장한다.
2. 내도매상품의 보유수량은 공급자가 도매상품 등록·수정에서 입력한 값으로 저장한다.
3. 도매주문상품의 보유수량은 계정 + 상품코드 단위의 저장값으로 두고, 배송확정 구매 수량을 누적한다. 다른 계정의 보유수량과 섞이지 않게 정의한다.
4. 내소매상품의 보유수량은 소매상품 등록·수정에서 입력한 값으로 저장한다.
5. 판매가능수량은 소매정보 단위로 저장한다.
6. 도매 가용재고는 저장하지 않고 산출한다.

#### 3-2. 증감

| 이벤트 | 대상 | 보유수량 | 판매가능수량 |
| --- | --- | --- | --- |
| 소매 주문 접수 | 3개 상품출처 공통 | −n | −n |
| 도매 주문 접수 | 내도매상품 (판매자 본인 상품) | −n | 변화 없음 |
| 소매 취소·반품 승인 + 재고 반영 | 소매 주문 품목 | +n | +n |
| 도매 취소·반품 승인 + 재고 반영 | 도매 주문 품목 | +n | 변화 없음 |
| 소매 구매자 즉시취소 | 소매 주문 품목 | +n | +n |
| 도매 구매자 즉시취소 | 도매 주문 품목 | +n | 변화 없음 |
| 도매 구매 배송확정 | 구매자의 도매주문상품 (계정 + 상품코드) | +n | 변화 없음 |

n은 주문 품목 수량이다.

#### 3-3. 처리 규칙

1. 차감은 주문이 생성되는 즉시 수행한다. 접수처리(주문확인·입금확인) 시점이 아니다.
2. 도매 주문 접수의 차감 대상은 판매자가 본인인 건에 한한다.
3. 소매 주문 접수는 판매가능수량 이내에서만 허용한다.
4. 도매 주문 접수는 도매 가용재고 이내에서만 허용한다.
5. 취소·반품 승인의 재고 반영은 공급자가 체크박스로 선택한다. 기본값은 선택이다.
6. 구매자 즉시취소는 체크박스 없이 자동 복원한다.
7. 재고 반영은 주문 전체 품목 단위로 일괄 적용한다. 품목별 부분 처리는 지원하지 않는다.
8. 복원 대상 품목이 하나도 없는 주문에는 재고 반영 체크박스를 노출하지 않는다.
9. 배송확정 증가는 주문 1건당 1회만 반영한다. 자동 배송확정과 수동 배송확정에 동일하게 적용한다.
10. 소매 취소·반품으로 판매가능수량이 복원되어도 판매상태는 자동으로 판매중이 되지 않는다.

#### 3-4. 불변 조건

1. 보유수량 ≥ 판매가능수량을 항상 유지한다.
2. 보유수량은 해당 소매정보의 판매가능수량보다 낮게 수정할 수 없다.
3. 소매 주문·소매 취소·반품은 판매가능수량과 보유수량을 같은 수량만큼 증감하므로 도매 가용재고가 변하지 않는다.
4. 도매 주문·도매 취소·반품은 보유수량만 증감하므로 도매 가용재고가 같은 수량만큼 증감한다.

#### 3-5. 산출 예

| 단계 | 보유수량 | 판매가능수량 | 도매 가용재고 |
| --- | --- | --- | --- |
| 초기 | 100 | 50 | 50 |
| 소매 10 접수 | 90 | 40 | 50 |
| 도매 20 접수 | 70 | 40 | 30 |
| 소매 10 취소, 재고 반영 | 80 | 50 | 30 |
| 도매 20 취소, 재고 반영 | 100 | 50 | 50 |

#### 3-6. 변경 전 → 후

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 소매 주문 접수 | 판매가능수량만 차감. 보유수량은 내소매상품만 함께 차감 | 3개 상품출처 모두 판매가능수량·보유수량 함께 차감 |
| 소매 취소·반품 재고 반영 | 판매가능수량만 복원 | 판매가능수량·보유수량 함께 복원 |
| 도매주문상품 보유수량 | 배송확정 구매분을 조회 시 합산 | 계정 + 상품코드 단위 저장값. 배송확정 시 증가, 소매 주문·취소에 따라 증감 |

## B. 소매 회원 배달지

### B-1. 수정 범위

| 구분 | 내용 |
| --- | --- |
| 변경 사항 | 배달지를 회원가입(고객용 프론트)의 선택 입력 정보로 정의하고, 관리자가 회원정보 상세에서 입력·수정할 수 있도록 변경 |
| 적용 화면 | 소매관리 > 회원관리 > 회원정보 상세 |
| 비변경 | 단일 배달지(배달지명·배달 주소·배달 요청사항) 관리, 다건 배달지 미지원, 주문 시점 배달지 스냅샷 |

### B-2. 정의

1. 배달지는 회원당 1개이며 배달지명·배달 주소·배달 요청사항으로 구성한다.
2. 배달지는 회원가입에서 선택 항목으로 입력한다. 입력하지 않은 회원은 배달지가 없는 상태다.
3. 배달지가 없는 회원도 회원정보 상세에서 세 항목의 입력란을 빈 값으로 노출하며, 별도 안내 문구는 노출하지 않는다.
4. 관리자는 회원정보 상세에서 세 항목을 입력·수정하여 저장할 수 있다.
5. 세 항목을 모두 비우고 저장하면 해당 회원은 배달지가 없는 상태가 된다.
6. 이미 생성된 주문의 배달지·요청사항은 주문 시점 값(스냅샷)이므로 회원 배달지 변경의 영향을 받지 않는다.

### B-3. 변경 전 → 후

| 항목 | 변경 전 | 변경 후 |
| --- | --- | --- |
| 배달지 없는 회원의 상세 화면 | "등록된 배달지가 없습니다" 안내만 노출, 관리자 입력 UI 없음 | 배달지명·배달 주소·배달 요청사항 입력란을 빈 값으로 노출, 안내 문구 없음 |
| 관리자의 배달지 입력·수정 | 불가 | 가능 |
| 배달지 성격 | 회원가입에서 입력하는 정보 | 회원가입에서 선택 항목으로 입력하는 정보 |
| 필수 항목 표기 | 회원정보 상세에서 필수 표기 없음 | 이름·이메일·회원주문 코드·휴대폰번호·인증번호 라벨에 `*` 표기 |

### B-4. 개발 확인 요청

| 번호 | 확인 항목 |
| --- | --- |
| 1 | 회원 데이터에 배달지가 없는 상태(null)를 허용하는 구조인지 |
| 2 | 세 항목을 모두 비우고 저장하면 배달지 없음 상태로 저장되는지 |
| 3 | 배달지 변경이 기존 주문의 배달지 스냅샷에 영향을 주지 않는지 |

## C. 가맹점 아이디 규칙·비밀번호 변경

### C-1. 수정 범위

| 구분 | 내용 |
| --- | --- |
| 변경 사항 | ① 아이디 입력 규칙을 09SCM 소매몰 가맹점 가입 화면 기준으로 통일 ② 본사가 가맹점상세에서 가맹점 비밀번호를 변경할 수 있도록 확대 |
| 적용 화면 | 본사 계정 아이디 입력(통합관리자 본사 등록·수정), 가맹점관리 > 가맹점상세 > 회원정보 탭 |
| 비변경 | 가맹점 본인의 시스템관리 > 회원정보 비밀번호 변경, 아이디 입력 규칙 중 길이·문자 외 항목(기존 가정 유지) |

### C-2. 정의

1. 아이디는 영문 소문자로 시작하고 소문자·숫자 3~20자로 입력한다.
2. 비밀번호는 가맹점 본인(시스템관리 > 회원정보)과 본사(가맹점상세 > 회원정보 탭) 모두 변경할 수 있다.
3. 본사는 가맹점상세 회원정보 탭의 "비밀번호 변경" 섹션에서 새 비밀번호·새 비밀번호 확인을 입력한다. 두 항목은 이 섹션 안에서만 필수이며 두 값이 일치해야 한다.
4. 비밀번호는 [비밀번호 변경]으로 회원정보 저장과 별도로 저장하며, 변경하면 "비밀번호가 변경되었습니다."를 노출한다.
5. 이용상태와 무관하게 언제든 재설정할 수 있으며, 임시비밀번호는 자동 발급하지 않는다.

### C-3. 변경 전 → 후

## D. 이용불가 전환 시 상품 처리 (기준일 2026-10-16)

### D-1. 수정 범위

| 구분 | 내용 |
| --- | --- |
| 변경 사항 | 가맹점을 이용불가로 전환하면 해당 가맹점이 등록한 도매·소매 상품 전체를 품절·미노출로 일괄 처리 |
| 적용 화면 | 가맹점관리 > 가맹점상세 > 이용상태 변경([이용불가]) |
| 비변경 | 이용제한의 차단 범위(신규 행위만 차단, 상품 상태 변경 없음), 도매공급권한 회수 규칙(도매상품만 처리, 소매정보 유지), 이용상태 전이표 |

### D-2. 정의

1. 이용불가로 전환하는 즉시 시스템은 해당 가맹점이 등록한 도매상품과 소매정보 전체를 처리한다.
2. 처리 값은 판매상태 품절, 노출여부 미노출이다. 도매(도매판매상태·도매노출여부)와 소매(소매판매상태·소매노출여부)에 모두 적용한다.
3. 대상은 내도매상품, 도매주문상품, 내소매상품의 소매정보를 모두 포함한다.
4. 보유수량·판매가능수량 값은 바꾸지 않는다.
5. 이용불가를 해제(이용대기 복귀)하거나 이후 이용승인해도 상품 상태를 자동으로 복구하지 않는다. 가맹점이 상품별로 직접 판매중·노출로 변경한다.
6. 이용제한 단계에서는 상품 상태를 바꾸지 않는다.
7. 이용불가 전환은 진행중 주문이 없을 때만 가능하므로(이용제한 → 이용불가 조건), 일괄 처리 시점에 진행중 주문은 없다.
8. 이용불가 확인 창 문구: "해당 계정은 로그인할 수 없게 되고, 등록한 도소매 상품이 모두 품절·미노출 처리됩니다."

## E. 도매상품 우리지역 시·군·구 전환 (기준일 2026-10-20)

### E-1. 수정 범위

| 구분 | 내용 |
| --- | --- |
| 변경 사항 | 우리지역 노출 판정을 "공급자와 같은 시·도"에서 "상품별 등록 지역(시·군·구 목록)에 구매자 사업장 주소의 시·군·구가 포함되는지"로 변경 |
| 신설 | 상품별 등록 지역 입력, 기본 지역, 최대 50곳 한도, 도매설정의 등록 지역(신규 등록 초기값), 장바구니 구매불가 처리, 주문 생성 시점 구매불가 검증 |
| 적용 화면 | 도매관리 > 내 도매상품 > 도매상품등록·수정, 소매관리 > 상품관리 > 도매상품전환, 도매설정, 도매상품 주문하기, 장바구니, 주문서·주문 생성 |
| 비변경 | 전국·우리본사 판정, 공급자 본인 상품 노출, 진행 중 주문 처리, 구매자 화면의 "우리지역" 필터·표기 |

### E-2. 정의

1. 등록 지역은 공급범위가 우리지역인 도매상품에 상품별로 저장한다. 지역 단위는 시·도와 시·군·구이며 시 아래에 일반구가 있으면 시와 구를 한 단위로 본다(예: 경기 수원시 영통구). "전체" 선택은 없다.
2. 노출 판정: 구매자 사업장 주소의 시·군·구가 상품의 등록 지역(기본 지역 + 추가한 지역)에 포함되면 노출한다. 본사 소속 여부는 판정에 쓰지 않는다.
3. 기본 지역은 공급자 사업장 주소의 시·군·구이며 삭제할 수 없다. 별도로 저장하지 않고 현재 사업장 주소에서 산출한다. 저장 대상은 추가한 지역뿐이며, 공급자의 사업장 주소가 바뀌면 기본 지역도 바뀐 주소 기준으로 적용한다.
4. 등록 지역은 기본 지역을 포함해 상품당 최대 50곳이다. 중복 등록은 불가하며 서버에서도 검증한다. 한도에 도달하면 화면에서 [지역 추가]를 비활성화한다.
5. 공급범위가 우리지역이 아닌 상태로 저장하면 추가한 지역은 저장하지 않는다(빈 목록).
6. 도매설정에 "공급범위(우리지역) 설정"(추가한 지역 목록)을 둔다. 신규 도매상품 등록·도매상품전환 화면에 진입할 때 이 목록을 상품 입력값으로 복사하며, 복사 이후 상품별로 수정할 수 있다. 도매설정을 나중에 바꿔도 이미 등록된 상품의 등록 지역은 바뀌지 않는다. 도매설정 등록 지역은 필수 입력이 아니다.
7. 공급자 본인의 상품은 공급범위와 관계없이 본인의 도매상품 주문하기 목록에 노출한다. 공급범위·등록 지역 변경은 이미 생성된 주문과 진행 중인 주문에 영향을 주지 않는다.
8. 장바구니 표시: 장바구니 품목이 공급범위·등록 지역 변경 또는 구매자 사업장 주소 변경으로 노출 대상에서 빠지면(도매노출여부는 노출 상태) [구매불가] 뱃지와 "공급범위가 변경되어 구매할 수 없습니다."를 표시한다. [품절]과 [구매불가]는 한 품목에 함께 표시할 수 있다.
9. 장바구니 제거: 도매노출여부가 미노출이 되거나 삭제된 상품은 안내 없이 장바구니 조회 시점에 제거한다. 품절과 미노출이 동시에 걸린 상품은 미노출 기준으로 제거한다.
10. 주문 버튼: 공급자 그룹에 품절 또는 구매불가 품목이 있으면 [전체주문]을 비활성화하고, 선택한 품목에 품절·구매불가가 포함되면 [선택상품주문]을 비활성화한다. 다른 공급자 그룹에는 영향이 없다. 그룹 하단 안내 문구는 두지 않는다.
11. 주문 생성 시점 재검증: 품목별로 재검증해 품절 → 구매불가 → 재고 부족 순으로 하나의 문구만 안내하고 주문을 생성하지 않는다. 재고 부족은 장바구니 뱃지 없이 이 시점에만 검증한다.
12. 문구
   - 등록 지역 영역 안내(모든 화면 공통): "본사 구분 없이, 등록한 우리지역(시·군·구 단위)에 사업장 주소가 있는 모든 가맹점에 노출됩니다. 최대 50곳까지 등록할 수 있습니다."
   - 공급범위 도움말: "우리지역: 공급자가 공급 가능한 우리지역으로 등록한 시·군·구의 구매자에게 노출됩니다."
   - 지역 추가 팝업 오류: "시·도를 선택해주세요." / "시·군·구를 선택해주세요." / "이미 등록된 지역입니다." / "최대 50곳까지 등록할 수 있습니다."
   - 주문 생성 시점 안내: "품절상품이 존재합니다." / "구매불가 상품이 존재합니다." / "재고가 부족한 상품이 있습니다."
13. 화면 규칙: 입력 영역의 필드 제목은 "우리지역"(도매설정의 섹션 제목만 "공급범위(우리지역) 설정"), 구성은 안내 문구 → [지역 추가]와 "등록 N/50곳" → 지역 칩 순서다. 기본 지역 칩에는 "(기본)"을 표시하고 삭제 버튼을 두지 않는다. 도매상품 상세의 공급범위는 "우리지역 (기본 지역 외 N곳)"으로 표기하고 추가한 지역을 다음 줄에 " / "로 구분해 나열한다.
